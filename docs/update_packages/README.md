# Папка пакетів версій

Тут зберігаються готові пакети оновлень, які створює `Product Center`.

## Що тут лежить

- `update_0001.json` - технічний опис пакета.
- `update_0001.md` - людський опис того ж пакета.

## Як це працює

1. У вкладці `Версії` ти натискаєш `Оновити перегляд`.
2. Програма дивиться, які файли ще не були упаковані.
3. Якщо все ок, ти натискаєш `Створити пакет версії`.
4. Програма створює новий номер, наприклад `update_0002`.
5. У папці з’являються нові `.json` і `.md` файли.

## Що важливо

- Не додавай сюди файли вручну без потреби.
- Не редагуй пакети руками, якщо це не термінова перевірка.
- Якщо файл вже був у попередньому пакеті й не змінювався, програма не повинна додавати його ще раз.

## Для чого це потрібно

Папка допомагає бачити історію версій:

- що саме було відправлено;
- коли створили пакет;
- який набір файлів входив у реліз;
- який був план оновлення для сервера.
